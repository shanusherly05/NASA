# NASA
Mission Control – Space Mission Simulator

Mission Control is an interactive educational space mission simulator that allows users to experience the role of a space mission director.

Users can design spacecraft, select mission destinations, choose scientific instruments, propulsion systems, launch vehicles, and communication systems.

The simulator evaluates important engineering parameters such as spacecraft mass, power requirements, fuel consumption, Delta-v, and mission budget.

After successfully completing the engineering checks, users can launch their spacecraft and manage mission operations by responding to unexpected challenges such as radiation storms, solar array contamination, and communication failures.

At the end, the simulator generates a mission performance score based on scientific achievements and spacecraft health.

Key Features:

- Interactive spacecraft design.
- Four mission destinations.
- Engineering constraint evaluation.
- Launch sequence simulation.
- Real-time mission resource monitoring.
- Unexpected mission challenges.
- Final mission performance report.

Objective: To provide an engaging and educational experience that helps users understand spacecraft engineering, resource management, mission planning, and decision-making.
